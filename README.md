# ちびそだて ver 0.2.0

たまごから育てて、ずかんを埋める1画面の育成ゲーム。
非公式の二次創作ファンゲームです。原作者さま・公式とは一切関係ありません。

## 遊び方
- たまごを「ちょうどいい温度」に保ってかえす（「おまかせ」なら10分で自動）
- あかちゃんの育て方で、育つ子が変わる
- お世話・しつけ・好物さがしをして、独り立ちまで育てる
- 結末はキャラごとに3つ。ずかんに記録される
- 独り立ちした子は「おうち」で暮らし、仲良くなったり、遊びに来たりする

## ファイル
- `index.html` / `style.css` / `game.js`：本体
- `data.js`：キャラ・結末・数値・セリフ（追加や調整はここ）
- `sprites/`：キャラ画像
- `sw.js` / `manifest.webmanifest` / `icon-*.png`：ホーム画面に追加・オフライン用

## テスト用
URLの最後に `#debug` をつけると、せっていに「はやおくり」が出る。

## 言語（日本語 / 한국어）
- せっていの「言語 / 언어」で切り替え（セーブデータは共通）
- 初回は端末の言語が韓国語なら韓国語で起動
- 韓国語版の `data.ko.js` / `game.ko.js` は自動生成。日本語版を直したら `python3 tools/make_ko.py` を実行する
- 訳を足すときは `tools/ko_strings.py` に追加
